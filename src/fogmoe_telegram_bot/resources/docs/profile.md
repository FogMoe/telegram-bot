# 个人信息 (/setmyinfo)
用户自己填写的个人信息，以及它和雾萌自己记下的印象有什么区别。

## /setmyinfo

- `/setmyinfo <内容>` 保存一段个人信息，在后续所有对话中生效。
- 不带参数直接发送，会先显示当前保存的内容，再给出用法说明。
- `/setmyinfo CLEAR` 清空已保存的内容。
- 最长 500 字符，超出会被拒绝并提示重试。

## 个人信息与印象的区别

- **个人信息**由用户自己撰写，只有用户能改，雾萌无法修改。
- **印象**是雾萌自己记下的，由她维护，用户不直接编辑。
- 两者同时存在时都要参考；发生冲突时，以用户自己写的为准。

印象、日记、以及对话历史怎么保存和遗忘，详见 memory 文档。
清除当前对话用 `/clear`，它的实际行为也在 memory 文档里。

## 什么时候用得上

用户问怎么让雾萌知道自己的某些设定、怎么改或清空这些信息、
或者疑惑雾萌为什么会知道某件事时，参考本文。

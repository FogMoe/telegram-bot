# 商城 (/shop)
用金币购买权限等级、永久记忆上限和彩票的地方，全部通过按钮操作。

## 权限等级

- 升级到 1 级 — 50 金币
- 升级到 2 级 — 100 金币
- 升级到 3 级 — 10000 金币

等级只能从当前等级往上买，已经达到或超过的等级无法重复购买。等级越高解锁的功能越多，
目前已知的门槛是 `/pic nsfw` 需要 2 级及以上（详见 pic 文档）。

## 永久记忆上限

- 记忆上限 +1 — 100 金币

提升的是永久归档能保存的条数上限。想让雾萌留住更久以前的对话，就是买这个；
归档、遗忘与超出上限后会发生什么，详见 memory 文档。

## 彩票

- 刮刮乐 — 10 金币，随机获得 0 到 20 金币
- 欢乐彩 — 1 金币，按概率获得奖励

刮刮乐是负期望还是正期望取决于运气，10 金币买一次，可能一无所获，也可能翻倍。

## 什么时候用得上

用户问怎么提升权限、怎么让雾萌多记一些、`/shop` 里都有什么、某个功能为什么用不了时，参考本文。
提到价格要说准，用户会照着算硬币够不够。

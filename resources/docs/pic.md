# 随机图片 (/pic)
从公开图库随机获取图片，消耗金币，成人内容需要权限等级。

## 命令

- `/pic` — 随机获取一张图片，消耗 5 金币
- `/pic nsfw` — 获取成人内容图片，消耗 5 金币，**需要权限等级 ≥ 2**
- `/pic help` — 显示帮助信息

## 规则

- 图片下方会有高清图按钮，点击获取原图，额外消耗 10 金币。
- 权限不足时使用 `nsfw` 选项会被拒绝，并提示前往商城购买权限等级（价格见 shop 文档）。
- 所有图片均从公开图库随机获取，雾萌无法指定内容或风格。
- 部分图片可能加载失败，这种情况金币会自动退还。

## 与 generate_image 的区别

`/pic` 是用户主动执行的命令，从图库随机抓取，扣用户金币。
雾萌自己的绘图能力是另一回事，由她按需生成，和这个命令无关。
用户说「给我张图」时要分清他想要哪种——想要随机图片就引导用 `/pic`，
想要她画点什么就直接画。

## 什么时候用得上

用户问怎么看图、为什么用不了 nsfw、高清图为什么又扣钱、
或者要求雾萌「发张图」而意图不明时，参考本文。

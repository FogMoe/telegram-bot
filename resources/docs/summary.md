# 归档摘要的生成状态
本文只说明 summary 的生成时机、长度限制和失败状态。

## 生成时机

每条归档记录创建后都会触发摘要生成。通常由后台任务处理；活动历史因超过容量而压缩时，系统会先尝试立即生成，失败后再交回后台。
摘要生成与归档写入是分开的，因此刚归档完时可能暂时还没有摘要。
后台任务从尚无摘要的归档中选择最新一条处理。

## 长度与失败

- 每次生成最多尝试 3 次。
- 最终摘要最多保留 2500 token，超出的尾部会被截去。
- 三次尝试全部失败时，不会写入替代内容；该归档继续保持尚无摘要的状态。

## 什么时候用得上

用户询问为什么刚归档的内容暂时没有摘要、摘要是否可能被截短，或生成失败后会留下什么时，参考本文。
